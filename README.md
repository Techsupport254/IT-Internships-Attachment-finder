# IT Internships & Attachment Finder

Python application that helps IT students in Kenya find internship and
industrial attachment opportunities.

## Overview

A tool aimed at students looking for IT internships/attachments, providing a
place to browse and search available opportunities.

## Features

- Browse IT internship and attachment listings
- Search/filter opportunities
- Python backend

## Tech Stack

- Python

## Getting Started

```bash
pip install -r requirements.txt
python main.py
```
